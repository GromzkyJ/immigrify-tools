## 🎯 How to Use This Template

### For New Projects

1. **Copy the template**:
   ```bash
   cp -r project-template my-new-project
   cd my-new-project
   ```

2. **Run setup**:
   ```bash
   ./setup.sh
   ```

3. **Follow prompts** and provide information

4. **Add GitHub Secrets** manually (script will guide you)

5. **Test deployment** by pushing to test branch

### For LLMs

1. Read `LLM_INSTRUCTIONS.md`
2. Read `SETUP_INSTRUCTIONS.md`
3. Gather information from user
4. Execute setup (automated or manual)
5. Verify deployment
